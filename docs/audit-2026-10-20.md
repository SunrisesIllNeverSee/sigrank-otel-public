# Dashboard audit — 2026-10-20

Three independent auditors (Board view · Sessions/Daily/Milestones/Usage/Model/Deltas/Card · Pipeline/provenance), each recomputing from raw files. No files were edited. Full reports with the owner's raw figures are kept privately.

## Verdict

**Arithmetic is correct.** Every total recomputed independently from `data/otel.jsonl` and the transcripts matched the API to the token (24h: requests, input, output, cache read/write, cost, prompts, tools, lines, commits, active time; sessions: every popup stat, rank, percentile, median; daily: a full 05:00 day; usage: per-model 7d).

**What is wrong is what the labels say the numbers are, which source a surface is reading, and three pipeline risks.**

## Fix list, ranked

### A. Wrong (code does not do what the label says)
1. **Subagents counter always 0** and `✦ AGENT` feed rows never appear. `score.mjs` counts trace spans named "subagent"; none exist. `claude_code.subagent_completed` logs and `agent:*` requests are the real signal.
2. **`board.typed === board.logged`** (`score.mjs` board row builder). Everything labelled "typed" scores on logged `input_tokens`, except the Υ calculator (`extras.mjs calc`) and the Milestones class. The calculator therefore disagrees with the headline it is opened from.
3. **Model popup "Top sessions · by Υ"** is sorted by total tokens and has no eligibility filter (`extras.mjs modelDetail`).
4. **Sessions "Class" column sort** sorts by Υ.
5. **Board `∑/Day` for board rows** divides the board's 7d (or all-time) total by the local window length: 7× too high at 24h; divided by your career length at All.
6. **Daily expansion "active Xh"** is wall-clock span; `active_time.total` is captured and unused there.
7. **Card Υ prints `22619.6K`** instead of 22.6M (`extras.mjs card` formatter).
8. **vs-career footnote** blames short history; the cause is the Jul 2 → Oct 11 gap (`dailies.length < 90` test).

### B. Misleading (true number, wrong or missing words)
9. **Tooltips say "each token you type"** for Υ, Leverage, Velocity; the denominator is API `input_tokens`.
10. **Board note "nothing estimated"** while `Typed/day` and feed `≈ N tok` are estimates, and 7d+ YOU comes from transcripts, not OTel.
11. **Three "you" on one screen** with no reconciliation: YOU row (OTel 24h / transcripts 7d+), public board row (dated, multi-platform), vs-career column (OTel+backfill).
12. **24h selector compares against the 7d board**: board rank "for this window", vs #1, ladder pin.
13. **Raw vs Metrics toggle switches dataset** for 7d+ (OTel tiles vs transcript tiles). "Logged input" shows two different numbers on the same screen.
14. **Harness exclusion undisclosed** on tiles: Logged input, Requests, Cost, ∑ Total all exclude harness; only the breakdown row reveals it.
15. **"live · synced"** means the receiver answered HTTP, not that telemetry is flowing.
16. **"Active time" headline** = Claude + you; tooltip says Claude's time with yours in brackets.
17. **Cost**: backfill rows carry $0, so 7d+/mixed sessions/days/models show partial dollars as if complete; sigrank 7d+ row hard-codes cost 0 (shows "—"); `cost_usd` is list price, not subscription spend, and nothing says so.
18. **"Class"** means three scopes: session volume tier (Sessions), day tier (Daily), career tier (Milestones/board).
19. **Milestones** "from snapshot deltas" (there are no snapshots); commit/lines milestones are since-telemetry, labelled as career.
20. **Usage view** window is rolling 168h/24h; Claude Code's `/usage` uses UTC calendar days and has no 24h. Per-model numbers and % formula do match.
21. **Model share disagrees across views** (Usage 93% opus vs Model popup/card 59–60%) because workflow-subagent traffic is in OTel views and excluded from the transcript-based Usage view, matching `/usage`. Neither says so.
22. Sessions window filter includes whole sessions whose last event is in-window; "All projects (N)" counts hidden ineligible rows; "deciles" are six uneven bands; Dur / Output-per-min are wall-clock; day graph on Board uses midnight while every other view uses 05:00; Four Degrees marks sit 4–5 orders of magnitude below both pins yet say "the best operators sit near here".

### C. Pipeline risks
23. **Rotation double-count (latent, high).** `store.mjs` rotates past months into `otel-YYYY-MM.jsonl`; `backfill.mjs` gap-fills only against `otel.jsonl`. A backfill run after 2026-11-01 re-imports the whole rotated month. Today: one duplicate (`req_011Cg4SHmY7w4hq9kzjNuMHP`, 0.43 s race).
24. **Day boundary inconsistency**: midnight in `summarize().days`, 05:00 in history/extras/sessions; rotation month is UTC. 13.8% of requests move between days depending on view.
25. **History coverage divergence**: `backfill.jsonl` holds May–Jul 2026 requests whose transcripts no longer exist on disk; 30d/90d/all breakdown includes them, tokenpull (YOU row) cannot. Those figures cannot be re-verified from source.
26. **Receiver downtime is never refilled**: 23 main-thread requests from the Oct 15 crashes are in neither file; backfill is one-shot.
27. **Parity leaks in `sourceOf`**: `compact` is counted on OTel but absent from transcripts; `sdk` → "you" while backfill skips sdk-cli.
28. **Scrub relies on Claude Code's own redaction** of `user_prompt`/`response`; the receiver's DROP regex would not catch them if `OTEL_LOG_USER_PROMPTS=1`. Current data is clean (0 paths, emails, keys).
29. `/api/usage` sums every transcript line with no dedupe (correct for mirroring `/usage`, wrong as a cross-check); `retentionDays` if ever set prunes OTel but not backfill.

### D. Findings that belong to sigrank-mcp / the board (not this dashboard)
30. **About two-thirds of subagent output is missing from transcripts** (corrected by the second-pass auditor; the first pass said 99%). Keep-last per request id, same rule as tokenpull: 7d subagent output OTel 6.13M vs transcripts 1.99M (32.5% kept; 27–42% per day). 1,350 of 5,915 subagent requests carry the stream placeholder (`output_tokens: 8, stop_reason: null`), 3,794 a partial count, 771 exact. Main thread matches 1.000. All sources combined: transcripts 4.04M of 8.18M = 49%. tokenpull, and so the board, counts about half of real output for this operator; subagent-heavy Claude Code operators are under-counted on Velocity and Υ. OTel is the only source with the full number.
31. **Devin adapter** splits an input field that is already "In" (CW unrecorded); only Codex truly combines In+CW. (From the Oct 17 session, confirmed here.)

## Second pass (adversarial, 2026-10-20 evening)
Ten biggest claims re-tested: 8 confirmed, 1 confirmed and worse (rotation double-count re-imports prompts and tool calls too, not just requests), 1 partly (subagent output: ~2/3 missing, not 99%). New findings:
- **N1 HIGH** `score.mjs load()` is append-only; a backfill rewrite while the receiver runs leaves it serving duplicates/missing rows until restart. D4 (daily backfill) must not ship before this is fixed.
- **N2 HIGH** D1 must also recompute `cutoff` and `liveSess` from all files, not only the request-id set.
- **N3 MED** `/api/pillars` labels transcript-rebuilt rows as `otel-cc`: 43% of 30d/90d requests, 79% all-time, come from backfill.jsonl. sigrank-mcp's otel source would submit that as OTel.
- **N4 MED** 3 compaction requests are 25% of `/api/pillars` 7d input (compaction sends fresh uncached input); with Υ ∝ 1/I² that moves Υ ~40%. Exclusion must apply to /api/pillars, not only the YOU row.
- **N5 MED** D5 is wrong about `sdk`: tokenpull counts sdk-cli transcripts; the leak is backfill's `entrypoint` skip. Keep sdk in the board-comparable row.
- **N6 MED** tokenpull failure is silent: `/api/sigrank` returns `{row:null,error}` and the dashboard shows "waiting for your first prompt".
- **N7 MED** export scrub leaks: public codename, the macOS username as a project name, every session UUID, MCP tool names revealing connected services. Fixed same day (see export.mjs).
- **N8 MED** no Host/Origin check on POST /api/submit; a web page could fire a submission if allowSubmit is on.
- **N9 MED** doctor never checks autostart/managed process; the Oct 15 crash loop was the LaunchAgent restarting into mid-edit files. (The auditor's claim that no LaunchAgent exists was wrong: `com.signalaf.tokenpull-otel` is loaded and running.)
- **N10–17 LOW** Sessions view rebuilt every 3 s (kills open select); `#view=usage` deep link dropped; out-of-window session deep link joins the ranking pool; unbounded raw body; 24h sigrank bypasses cache; 29% of stored rows unused; api_error rows never shown; card says "1d"; `days=abc` → all-time.
- **D7 check needed:** the view sums 6.83M output for 7d where dedupe gives 3.04M (2.25×). It matched the owner's pasted /usage on Oct 15–16; re-check once against today's panel before accepting "no code change".
